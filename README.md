# GoodGrocer 🛒

**GoodGrocer** is a Django-based e-commerce platform prototype designed for online grocery shopping. This project demonstrates the implementation of Django for backend development, complemented by Bootstrap for responsive frontend design. It serves as a practical application of full-stack development skills, focusing on user-centric features and seamless user experience.

---

## 🚀 Features

- **User Authentication**: Secure user registration and login functionalities.
- **Product Catalog**: Display of grocery items with details and images.
- **Shopping Cart**: Add, update, and remove items from the cart.
- **Order Management**: Process orders and maintain order history.
- **Responsive Design**: Mobile-friendly interface using Bootstrap.

---

## 🛠️ Technologies Used

- **Backend**: Django (Python)
- **Frontend**: HTML, CSS, Bootstrap
- **Database**: SQLite
- **Version Control**: Git

## 📌 Installation

Follow these steps to set up and run the project locally:

### 1. Clone the Repository

git clone https://github.com/Mr-AbhiJoshi/GoodGrocer.git
cd GoodGrocer

### 2. Create a Virtual Environment

python -m venv env

### 3. Activate the environment

#### a. On macOS/Linux:

source env/bin/activate

#### b. On Windows:

.\env\Scripts\activate

### 4. Install Dependencies

pip install -r requirements.txt

### 5. Apply Migrations

python manage.py migrate

### 6. Run the Development Server

python manage.py runserver

Access the application at: http://127.0.0.1:8000/
